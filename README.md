# EstateBook

그림과 직접 조작하는 실험으로 배우는 한국 부동산 입문 교과서.

## 구성
- 15개 학습 챕터, 30개 본문 실험, 83개 용어
- 면적, 입지, 수요·공급, 전월세, 대출, 상환, 권리, 계약, 비용, 수익률, 개발, 주거 설계실
- 반응형 화면, 다크 모드, 전체 검색, 퀴즈, 브라우저 내 학습 진도

## 실행과 배포
빌드나 외부 라이브러리가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다. 로컬에서는 `python3 -m http.server 8000` 후 브라우저로 열 수 있습니다. GitHub Pages의 main 브랜치 / (root)에서 배포합니다.

## 교육 모델
모든 매물·시세·지도는 가상입니다. 법정 세율과 대출 규제 비율은 구현하지 않으며 입력값은 교육 가정입니다. 단순 계산과 실제 계약·심사는 다릅니다. 실험별 생략 조건과 공식 출처는 웹의 출처 페이지에서 확인하세요.

## 구조
- index.html: 앱 골격
- style.css: 반응형 디자인
- content.js: 챕터, 용어, 출처
- models.js: 실험 설정과 계산
- app.js: SVG 그림, UI, 탐색
- beginner.js: 중학생용 질문, 상황 버튼, 핵심 조작, 처음·현재 비교

## 쉬운 실험 흐름
생각해 보기 → 직접 바꾸기 → 그림 관찰 → 한 문장 결론. 추가 조건과 수식은 접어서 제공하며 실제 현금 지출과 기회비용을 분리해 표시합니다.
